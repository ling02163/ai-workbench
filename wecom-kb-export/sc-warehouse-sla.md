# 场景卡 · 仓库 SLA 推诿与能力

> 分类：团队管理 ｜ 标签：团队能力  
> 摘要：仓库出库超时、和客服组互相推锅？管住自己的手，把责任交还回去，定交接口径让他们自己守。

对应框架卡：第20课-团队管理-能力问题（推诿部分参 第19课-动力问题）
适用：仓库出库超时、盘点对账出错、和客服组互相推锅；你一兜底，团队能力永远上不来。

## 一、场景画像

仓库这周有 3 单出库超 24 小时，客服组说仓库压单、仓库说客服信息给晚了，两边在群里对着甩。盘点表又对不上，你半夜自己把账重算一遍——第二天他们照旧，还多了一份"反正玲姐会兜"的依赖。

## 二、用哪张卡

- **第20课 能力问题**：核心是**管住自己的手**。误区是"我的能力＝达成目标的唯一能力"；认知是**管理岗是杠杆**，用团队整体劳动时间 1+1>2；方法是**能力觉察法**——测评建信心 → 讨论优势给认可 → 探索他的**能力模式**（面对目标他怎么用自己的优势达成）→ **卡点时不伸手**，回优势启发，忍住"黑色想象"。

- **先分岔**：出错是**不会做**（→ 20 课能力）还是**不愿做/在推**（→ 19 课动力，找动力位置）。同一个人可能两样都有，先处理动力再谈能力。

- **推诿另加 第23课**：在群里对甩时，别评价"你拖了大家后腿"，改成事实＋提问。

## 三、操作步骤

- **拆事实，不拆立场**。把 3 单超时的时间线摆出来（谁几点收到、几点出库），只呈现 4W1H，不定谁的责任。推诿多半死在"各说各的印象"。

- **一对一分开谈，不在群里断案**。群里断案 = 公开评判，两边都防御。

- **判断不会 / 不愿**：问"这一单你当时是怎么处理的？"如果他讲不出方法 → 不会；如果讲得出但没做 → 不愿。

- **不会 → 交还责任＋只启发不代做**：让他按**自己顺手的方式**先做一遍，你不插手；卡住时不给答案，回到他的优势问"你还能从哪试"。做完再一起看哪里能更好。

- **推诿 → 定交接口径**：让两边自己约定"信息几点前给、超时怎么报"，你只做见证，不做裁判。他们自己定的规则才有动力守。

- **忍住"黑色想象"**。他第一次做得比你慢、比你糙，是正常成本；你一伸手，能力和动力一起归零。

## 四、可直接套的话术

**① 交还责任（把兜底还回去）· 当面说**

```
"这次【填空：盘点表/超时单】你按你自己的方式先做，我做的过程中不插手；做完我们一起看哪里还能更好。做不完也没关系，卡在哪你告诉我。"
```

**② 探他的能力模式 · 一对一**

```
"你处理【填空：出库/对账】的时候，自己最顺手的办法是【填空：先按客户批次分堆 / 先把异常单挑出来】对吧？那这次就用你这一招，别学我的做法。"
```

**③ 卡点启发（他来求救时的标准回应）· 当面或微信**

```
"卡在这了？回到你【填空：细致/条理/沟通】这个优势上，你觉得还能从哪儿试一下？我先不替你做——你想出来的办法我们就用你的。"
```

**④ SLA 超时的绩效沟通（关系不够时先存钱）· 一对一**

```
"我注意到最近有 3 单出库超过 24 小时，最近一次是【填空：周二那单】。我先不下结论，想问你——你觉得卡在哪？"
```

**⑤ 打断推诿、把责任交回两边 · 群里或碰头会**

```
"我不追谁的责任。我要一个结果：【填空：客服几点前把订单信息给到仓库、仓库几点前出库、超时谁在群里报】。你们两边自己定，定完发我，我按你们定的看数据。"
```

**⑥ 拒绝当救火队员 · 当面说**

```
"这单我不接手了。不是不管你，是我一直替你做，你这块能力就一直起不来。你先做，卡住随时找我，我陪你想，但不替你写。"
```

## 五、复盘自问

- 这次我**伸手了吗**？如果伸了，我本可以问哪一句代替动手？

- 我是不是在用**我的方法**当唯一标准？他那套做法虽然不像我的，结果达成了吗？

- 这次谈的是能力还是动力？我判断对了吗（他是讲不出方法，还是讲得出没做）？

- 交接规则是**我定的**还是**他们自己定的**？他们自己定的，这周守住了几次？
