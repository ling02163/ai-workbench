# 给「重要不紧急」钉死固定锚点：每日时间表模板

> 分类：效率体系 ｜ 标签：时间管理  
> 摘要：我的真实作息基线 + 工作日/周末模板 + 兜底策略 + 周复盘 4 问。重要的事不是挤时间，是钉死锚点。

这套时间表是我自己跑通的。核心是：每天只锁 3 件要事 + 几个固定锚点，计划崩了也不至于全崩。

## 我的真实作息基线

- 07:00 起，23:00 前睡；精力高峰在**晚上**，白天售后突发不可控。

- 周二 / 周四 18:00-20:00 留公司「学习夜」。

## 工作日模板

| 时段 | 安排 |
| --- | --- |
| 07:00-07:10 | 晨间规划，列 3 件要事 |
| 09:00-18:00 | 工作（碎片时间清小任务） |
| 18:00-20:00 | 周二/四：公司学习夜 |
| 20:00-22:30 | 晚间专注（写作/深度活） |
| 22:30-23:00 | 复盘 + 明日规划 |

## 周末模板

可支配约 4h/天：周复盘 + 大块任务 + 陪伴 + 运动；父母联络、周复盘固定**周日晚上**。

## 兜底策略

- 昼间突发 → 学习/生活块顺延到晚间，不硬挤。

- 每日只锁 3 件要事 + 固定锚点，避免「计划一崩就放弃」。

## 周复盘 4 问

① 目标达成率多少？② 哪些好 / 哪些不好？③ 根本原因是什么？④ 下周怎么调？复制

> 💡 锚点思维：固定动作（晨规划、学习夜、复盘）像钉子，钉在每天；浮动任务往里填。钉子在，一天就不会散。
