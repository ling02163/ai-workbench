# 场景卡 · 客服组员动力与反馈

> 分类：团队管理 ｜ 标签：团队动力  
> 摘要：组员被投诉后越来越消极、难工单往外推？先存关系账户，再给事实反馈、找到她的动力位置。

对应框架卡：第19课-团队管理-动力问题 ＋ 第23课-反馈技术
适用：组员没动力、推诿工单、被投诉后越来越消极，你想纠错又怕他炸。

## 一、场景画像

客服组小 A 这周被客户投诉 3 次，都卡在退款环节；难工单她一律说"太忙"往同事那推，只接简单单。你嘴上没说，心里憋着，最后 SLA 快超时了自己上手兜底——她不领情，你两头受气。

## 二、用哪张卡

- **第23课 反馈技术**（先用）：核心是**不带评判的镜像呈现**——事实（4W1H＋她原话）→ 我的感受/假设（不是结论）→ 可能性词汇收尾（"你觉得呢？"）。前提是**关系账户余额够**，不够先存钱。

- **第19课 动力问题**（后用）：核心是破除"我的动力＝下属的动力"，用**动力觉察法**找到她自己的动力位置，再借她的动力把工作激发起来。

- 关键判断：她是**会做但不做**（动力），不是不会做。别错翻 20 课。

## 三、操作步骤

- **先存钱，不先下结论**。用提问和倾听搞清她的现状和典型场景："最近退款单是什么情况？"——这一步只听，不纠。

- **判断关系余额**。看她投入度、表达欲、非言语是不是松弛。如果沉默 / "yes but" / 跳题，先退，改天再谈；**推 2-3 次不行就停**，硬推会掉分。

- **给事实反馈，不给评价**。说"本周你被投诉 3 次都在退款环节"，不说"你总跟客户急"。补一句感受与假设，收一句"你觉得呢？"

- **切到动力觉察**（同一次或第二次面谈）：① 让她做优势测评、读报告，先讲发光面建信心；② 和她讨论她的优势并正面认可；③ 就着优势探她的动力位置（被认可？验证一个方法有效？帮到人？）。

- **把工作挂到她的动力位置上**。例：共情力强 → 让她带新人做客户答疑、当"投诉话术样板"；分析力强 → 让她拆退款投诉的根因、出一版流程建议。

**同时：**停止替她兜底。救火队员这件事既无效又不讨好。

## 四、可直接套的话术

**① 纠错反馈（4W1H＋感受＋可能性）· 当面说**

```
"我注意到本周有 3 单投诉都出在【退款】环节，最近的一次是【周三那单，客户说等了 4 天】。我听到你当时说【"这不是我能决定的"】，我的感受是你其实想快点帮客户解决，只是卡在了流程上——我不确定是不是这样，你觉得呢？"
```

**② 探动力 · 一对一面谈**

```
"你做事情最有劲的时候，通常是【被认可 / 自己验证了一个方法有用 / 实实在在帮到了客户】的时候，对吗？我们看看能不能把这种感觉带到【难工单/带新人】这件事里。"
```

**③ 破"我的动力=你的动力"误区 · 当面说**

```
"我不是要你像我一样盯 SLA 数字，你更吃【共情/沟通】这一套。我们换一个能让你动起来的方式——【填空：让你带新人答疑 / 让你出一版退款话术】，你愿意试一个月吗？"
```

**④ 确认是不愿还是有困难 · 微信可发**

```
"小 A，我看到【难工单/跨部门协调】这块最近一直接不动，我想确认一下，是你觉得这件事【没必要 / 没动力 / 有困难】？哪个更接近？先不用给我方案，说实话就行。"
```

**⑤ 遇到阻抗时（她沉默/敷衍）· 当面说**

```
"我看到你沉默了，是不是我刚说的让你不太舒服？如果是，你直接告诉我，我们换个说法聊。"
```

## 五、复盘自问

- 我刚才给的是**事实描述**还是**评价**？有没有引用她的原话、有没有留一句"你觉得呢"？

- 谈之前我判断过**关系账户余额**吗？她防御的时候我是退了，还是硬推了？

- 我找到她的**动力位置**了吗？还是我又在用"我的动力"要求她？

- 这周我有没有再替她兜底？如果有，那次我本可以问什么代替伸手？
