# 25 个万能文案公式速查表

> 分类：沟通汇报 ｜ 标签：文案  
> 摘要：25 个经过验证的说服性文案结构（AIDA、PAS、FAB…），配模板和适用场景。写汇报、写推送、写提案，直接抄。

同样的意思，换个结构说出来，说服力天差地别。下面 25 个是从经典文案学里挑的「万能结构」，每个都给了可直接填空的模板。收藏这页，写材料前翻一翻。

| 公式 | 结构 | 适合场景 | 模板（把 {} 换成你的内容） |
| --- | --- | --- | --- |
| AIDA | 注意→兴趣→渴望→行动 | 引流 CTA、通用说服 | {吸引眼球的钩子} → {有趣细节} → {想要的结果} → {行动} |
| PAS | 问题→放大→解决 | 销售页、痛点页 | 你在为{问题}头疼，它正悄悄消耗{代价}，{方案}能解决。 |
| 4Ps | 承诺→画面→证明→推动 | 落地页、获客 | {好处承诺} → {未来画面} → {证据} → {马上行动} |
| Before-After-Bridge | 前→后→桥 | 蜕变案例 | 以前：{旧状态}。以后：{新状态}。桥梁：{怎么做到} |
| QUEST | 确认→理解→教育→刺激→过渡 | 方案匹配客户 | {确认身份} → {共情} → {讲方案} → {激起欲望} → {导向 CTA} |
| Star-Story-Solution | 人物→故事→方案 | 人格化品牌 | {主角} → {它的困境} → {它的解法} |
| FAB | 特点→优势→利益 | 功能介绍 | {功能}：{它做什么} → {为何重要} → {帮你得到什么} |
| What If | 如果…… | 开场钩子 | 如果不用{常见障碍}，你也能{想要的结果}？ |
| How To | 怎么做 | 教程类 | 如何在{ timeframe }内{达成结果} |
| Number List | 数字清单 | 易扫的好处列表 | {N} 个{方法}帮你{结果} |
| Question Hook | 反问 | 开场互动 | {让人点头的问题}？方法在这里。 |
| Proof Stack | 数据→来源→意义 | 建立可信 | {亮眼数据}（来源：{可信来源}），这意味着{对你的意义}。 |
| Future Pacing | 想象未来 | 愿景类 | 想象：{渴望的未来场景}，这正是{方案}给你的。 |
| Social Proof | 谁+结果+原话 | 客户证言 | {客户}把{指标}提升了{幅度}：「{原话}」。 |
| Scarcity Urgency | 限量+期限 | 促成行动 | 仅剩{数量}，{日期}截止，{错过的代价}。 |
| Cost of Inaction | 不做的代价 | 推动改变 | 每{周期}不解决{问题}，你就亏{量化损失}，一年就是{更大数字}。 |
| Simple Benefit | 你得到 | 价值直给 | {方案}：你得到{具体好处}。 |
| Objection Preempt | 预判+化解 | 答疑/FAQ | 你也许会想{顾虑}，其实{用证据反驳}。 |
| Comparison Frame | 对手 vs 我们 | 竞争定位 | {对手做法}：{局限}。{我们的做法}：{优势}。 |
| Pain-Claim-Gain | 痛点→断言→收益 | 价值主张 | {痛点}？{关于方案的强断言}。结果：{具体收益}。 |
| One Thing | 唯一关键 | 聚焦 | {受众}要{结果}，最该做的一件事是{那一件事}。 |
| Riddle Open | 谜题→揭晓 | 开场悬念 | {谜题/悖论}，答案是{揭晓}，对你意味着{意义}。 |
| Hero Journey | 平凡→挑战→蜕变 | 叙事结构 | {平凡主角} → {遇见挑战} → {靠方案克服} → {完成蜕变} |
| Value Stack | 分项+总价 | 价格/投入 | {项1}(值${X})+{项2}(值${Y})…=总价值${Z}，你的投入仅${实价}。 |
| Power Statement | 断言+证据 | 权威感 | {有力断言}。{支撑事实}。 |

> 💡 用法：先想清楚这页要读者「做什么」(CTA) 和「什么情绪」(好奇/信任/紧迫)，再挑一个最贴的结构套模板。别硬凑，结构是为说服力服务的。
