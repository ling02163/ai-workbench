# 飞书多维表格当时间管理中枢：4 表 + 6 脚本

> 分类：技术实操 ｜ 标签：飞书  
> 摘要：4 张多维表格 + 6 个 Python 脚本，把愿景/待办/日报/项目全收口到飞书，AI 标记完成即改状态。

光连上飞书不够，要让它真正「接管」你的时间管理。我用 4 张多维表格 + 6 个 Python 脚本搭了套自动化套件。

## 4 张表（base）

| 表 | 作用 |
| --- | --- |
| 愿景看板 | 5 年方向 |
| 每日待办 | 晨间 AI 写入今日重点 |
| 每日日报 | 收工 AI 回写完成项 |
| 工作项目 | 中长期项目进度 |

## 6 个脚本职责

| 脚本 | 做什么 |
| --- | --- |
| feishu_build_system | 建 4 表并灌种子数据 |
| feishu_todo | 晨间写今日重点 |
| feishu_daily | 晚间回写日报 |
| feishu_mark_done | 标完成（改状态为绿） |
| feishu_gantt | 生成甘特图 |
| feishu_test_send | 发群消息测试 |

## 统一运行命令

cd '<项目文件夹>' && /Users/liling/.workbuddy/binaries/python/versions/3.13.12/bin/python3 <脚本> [参数]复制

## 双轨一致

待办清单是唯一源：AI 标记完成 → 改飞书状态，开工卡和飞书待办永不打架。

> 💡 进阶：把脚本迁到团队版（复制 base + 设字段权限），就能从「个人别漏别忘」升级成「团队管理工具」。
